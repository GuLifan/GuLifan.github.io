# Acceptance Checklist

## Content

- [ ] All six approved sections are present in the approved order.
- [ ] Name, role, dates, email, GitHub, and ORCID match approved facts.
- [ ] Exactly four approved pinned projects are displayed.
- [ ] Three publications and two pending conference abstracts are separated.
- [ ] Honors are explicitly labelled as selected.
- [ ] No CV file, download control, PI name, IELTS score, personal-qualities
      section, or organizational-role section is present.

## Functionality

- [ ] Jekyll production build and automated validation pass.
- [ ] Navigation, theme toggle, email, DOI, GitHub, and ORCID links work.
- [ ] GoatCounter is omitted when its code is blank and enabled when configured.
- [ ] Site remains readable with JavaScript disabled, except the theme toggle.
- [ ] Google Scholar automation and Google Analytics are absent.

## Quality

- [ ] Visual review at mobile, tablet, and desktop widths.
- [ ] Keyboard-only navigation review.
- [ ] No horizontal overflow, clipped text, layout overlap, or broken images.
- [ ] Metadata, canonical URL, JSON-LD, sitemap, robots.txt, and 404 page exist.
- [ ] Glass surfaces have a readable fallback without backdrop-filter.

## Release

- [ ] Public repository is named `GuLifan.github.io`.
- [ ] Default branch is `main`.
- [ ] GitHub Pages source is GitHub Actions.
- [ ] Deployment workflow completes successfully.
- [ ] `https://gulifan.github.io/` returns the expected page over HTTPS.
- [ ] Only one Pages deployment workflow is active for a push.
